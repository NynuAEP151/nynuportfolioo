Entrar

O painel salva os vídeos direto no seu repositório do GitHub. Você só precisa fazer isso uma vez neste navegador.

Como criar o token
  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Clique em Generate new token, dê um nome (ex.: painel nynu) e escolha a validade.
  3. Em Repository access, marque Only select repositories e escolha o repositório do site.
  4. Em Permissions → Repository permissions, coloque Contents em Read and write.
  5. Gere o token, copie e cole aqui. Ele fica salvo só neste navegador.
